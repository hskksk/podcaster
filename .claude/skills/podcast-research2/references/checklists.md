# 提出前テストと見直し順

`SKILL.md` ステップ 4 の直前。失敗は感想ではなく、直しを指す。

分析版から外したもの: Now-what（提言の四要素）、クエリ追跡、Finding/Action ノード、lede の判断待ち Purpose、確度付き機構、推奨節の配置。残したのは層、見出し、著者非依存、遠目、言語の作法。

## 提出前に走らせるテスト

| テスト | 通過条件 | 失敗したときの直し |
|------|----------------|-------------------|
| **一文テスト** | 原稿を読まずに、見取り図を一文で言える | 調査に答えがないか、答えが複数。問いに答える一つを選ぶ |
| **単独テスト** | L1 だけ渡された読者が、テーマの見取り図を言える | L1 が各節の要約になっている。6 スロットから書き直す。見取り図と主張から始める |
| **単独見出しテスト** | 本文なしで見出しだけ読む。付録も含め、賛成・反対できることを主張していない | 見出しが結論。第一文へ移し、節を名付ける。**Lede-and-Titles より先。主張する見出しは後者を通しながら文書を失敗させる** |
| **Lede-and-Titles** | 見出しと各節の第一文を順に読むと論になる | 第一文が話題か方法。主張に置き換える。見出しに上げない |
| **三つ規則** | L2 の主張は三つ、多くて四つ | 重なる主張を合併し、残りは L3 か次の調査へ |
| **非重複** | 同じ根拠に乗る節が二つない | 合併するか、本当に違う軸を見つける |
| **枠組みチェック** | 枠組みが、細部が一つに見える理由を述べている | 「A と B は関係する」で止まっている。理由を足すか、見取り図側の事実に落とす |
| **だから何チェック** | 各節末が、見取り図への寄与で終わる | 年号や定義で終わる節は尚未完。寄与を書く。行動指示で終わらせない |
| **著者非依存** | セッションを見ていない人にも正しく読める。会話、見せていない検索結果、口頭の補足に頼らない | 欠けた文脈を本文へ折り込むか、限界として明示する |
| **分量テスト** | L1 + L2 がおおよそ 2 万字。パディングで主張を増やしていない | 主張は切る。証拠は L3 へ移す。2 万字に届かせるために節を足さない |
| **図の一文** | 本文の図・表すべてに、要点を述べる文がある | 文を書く。図を消したり散文に潰したりしない。どの主張も使わない図だけ外す |
| **付録テスト** | L2 の 20% 以上を、主張を弱めずに L3 へ移せる | 移す |
| **証拠の生存** | L3 に、棄てた検索枝とその根拠、各 L2 主張が乗る出典が残っている | 短くする過程で消している。戻す |
| **lede スロット** | L1 に 6 スロットがこの順で、それ以外がない: 背景、目的、見取り図、範囲、枠組み、主張 | 欠けは目的か枠組みが多い。余分は副次的な内訳が上がってきた印。L2 か L3 へ戻す |
| **目的チェック** | lede が成立させる理解を名指し、使った方法を名指していない | 「本稿は X を調査する」は方法。読者が持ち帰る見取り図に置き換える |
| **見取り図対主張** | 主張は見取り図とは別で、読者が拒める立場である | 主張の文を消す。何も失われないなら言い換え。レポートが引き受ける整理を書く |
| **提言なし** | 推奨節がない。誰が・いつまでに、がない。節末が行動指示になっていない | 理解への寄与に書き換える。残る未知は範囲か L3 へ |
| **構成インデックス** | 構成ブロックが lede と最初の節の間にあり、行数と L2 節数が一致する | 両方数える。行のない節は辿り着けない。節のない行は切った主張の残骸 |
| **構成キャプション** | 構成の一文が、主張の関係（連鎖・並列・対比）を名指し、付録を列挙する | 足す。関係を書かないと、どれか一つ落としてもよいと読まれる |
| **遠目テスト** | ぼかすと帯が見える — 見出し、段落の空白、表。真っ黒な長方形ではない | 段落を 3〜5 文に切り、つながりの語を先頭へ、値の列は表へ |
| **接続チェック** | 二段落目以降、関係が自明でない段落は、つながりの語で始まる | 文中から先頭へ移すか、書く |
| **言語の作法** | 出力言語の参照を読み、適用した。日本語 — 修飾順、係り受け、ねじれ、読点。英語 — 動詞が行為を運ぶ、主語と動詞が近い、旧→新 | 該当参照のチェックを本文にかける。構造テストを全部通しても、この層はカバーされない |
| **負荷監査** | どの段落も、同時に四つ以上を持たせない | 段落を割るか、考えを一つずつ出す |
| **孤児識別子** | L2 で名前を出した表・ファイル・内部 ID は、二度以上使われている | ものを散文で説明し、識別子は L3 へ |
| **出典チェック** | L2 の事実は出典に辿れる。見解はこのレポートの整理だと文が示す | 出典を付けるか、見解として書き分けるか、外す |
| **口調チェック** | 未確認の文が、未確認だと見える | 何を確認し、何をしていないかが文に出るように直す |

## 見直しの観点

情報設計を、調査の質と並べて見る。失敗は指名テスト、箇所、必要な直しで報告する。印象で報告しない。

| 観点 | 見ること |
|------|----------|
| **答え** | L1 が問いを答えているか。L1 だけで見取り図が言えるか。6 スロットがあるか。特に目的（理解）と枠組み、見取り図と別の主張か |
| **層** | 辞典が L2 に座っていないか。支えるものが L3 に取り残されていないか。棄てた枝と出典が付録に生き残ったか |
| **主張の数** | 三つ（±1）、重ならないか |
| **節の契約** | 第一文が主張、一方向、図が主張に付く、節末が寄与か |
| **見出し** | 単独で読むと名指しているか。主張する見出しは Lede-and-Titles を通す — 見出しを先に単独で見る |
| **散文と箇条書き** | 推論は段落か。箇条書きだけの節がないか |
| **事実と見解** | 区別できるか。提言が混ざっていないか |
| **著者非依存** | セッション、見せていない検索、口頭の補足に頼っていないか |
| **口調** | 確認済みと未確認が分かるか。範囲が L1 にあり、末尾だけではないか |
| **形** | 構成ブロックがあり、節と行が一対一か。遠目テストを通るか |
| **文の読みやすさ** | 出力言語の参照。日本語: 係り先から遠い修飾、入れ子、主述のねじれ、境目すべての読点、逆接の「が」の連打、遠い代名詞。英語: 名詞化、主語と動詞の分離、新情報が先、逃げの受身、壊れた並列 |
| **文体** | 埋め草、翻訳調、擬人、主張の繰り返し |

## 自己採点では信用できないテスト

著者は、自分の原稿が失敗しているテストを通してしまう。失敗は、事実を調べれば済む場所ではなく、判断が要る場所に集まる: 見出し、節末が寄与か、出典に辿れるか、未確認が未確認に見えるか。層・付録・箇条書き vis-à-vis 散文のような構造規則は自己採点に耐える。解釈の規則は耐えない。

二つ従う。第一に、解釈のテストを自分で通したときは仮とし、通過を稼いだ文を引用する。文を名指すことが、偽の通過を捕まえる。第二に、残す原稿は書いていない人に見てもらう。このファイルから、指名テスト、箇所、直しで返す。

## すでに長すぎる原稿の直し順

並べ替えを先にすると無駄で、答えを決めずに切ると間違ったものを消す。

1. 見取り図を一文で書く。他はすべてこれに対して判定する。
2. それを支える三つの主張を選ぶ。既存の節にラベルを付ける: 主張を運ぶ／運ばない。
3. 後者を、名前の付いた付録へ移す。まだ消さない。
4. L1 を 6 スロットで書く: 背景、目的、見取り図、範囲、枠組み、主張。
5. 残した各節の第一文を主張に書き直す。
6. その第一文から構成ブロックを作り、行数と節数を数えてから先へ進む。
7. そこで切る: 残した節の中の繰り返し、孤児識別子、図の実況。
8. 上のテストを走らせる。
