# 週次ワークフロー・保存・提示

## 週の特定

- デフォルト: **実行日を含む週**の月曜〜金曜
- ユーザーが「今週分」と言った場合も同様
- ユーザーが月曜の日付（例: `2026-10-19`）を渡した場合は、その週の月〜金を使う

## ディレクトリとファイル名

**保存先（リポジトリ内）:**

中学受験向け教材は `content/`（Wiki・クリップ）と分離し、次のパスを使う。

```
chugaku-juken/sapix/grade5-japanese-history/week-<月曜のYYYY-MM-DD>/
```

`chugaku-juken/README.md` にディレクトリの目的を書いてある。Keystatic・公開サイト・ポッドキャスト ingest の対象ではない。

**ファイル数:** 5（月〜金で各1つ）。ZIPにまとめない。

**ファイル名の例**（曜日とテーマが分かること）:

```
月曜_平城京と奈良時代のはじまり.md
火曜_聖武天皇と東大寺の大仏.md
水曜_国分寺と仏教のちから.md
木曜_平安京への遷都794年.md
金曜_奈良時代のおわりと平安の扉.md
```

- 先頭に曜日（`月曜`〜`金曜`）
- アンダースコアの後に短いテーマ
- 拡張子 `.md`
- テーマはその日の焦点を表す（当該テキストの範囲内）

## ユーザーへの提示

1. 5ファイルを書き終えたら、**各ファイルを個別にリンク**する（リポジトリ内相対パスでよい）
2. リンクテキストに **曜日とテーマ** を含める
3. ZIPアーカイブは作らない・渡さない
4. チャットのみで渡す場合（Write不可）: 曜日ごとに見出しを分けて本文を貼る。ファイル添付を **したと偽らない**
