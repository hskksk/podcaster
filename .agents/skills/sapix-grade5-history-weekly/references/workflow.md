# 週次ワークフロー・保存・提示

## 週の特定

- デフォルト: **実行日を含む週**の月曜〜金曜
- ユーザーが「今週分」と言った場合も同様
- ユーザーが月曜の日付（例: `2026-10-19`）を渡した場合は、その週の月〜金を使う

## ディレクトリとファイル名

**保存先（リポジトリ内）:**

中学受験向け教材は `content/`（Wiki・クリップ）と分離し、次のパスを使う。

```
chugaku-juken/sapix/grade5-japanese-history/weeks/<月曜のYYYY-MM-DD>/
```

`chugaku-juken/README.md` にディレクトリの目的を書いてある。同じコースの `course.yml` は公開サイト `/juken` の紹介文で、週次の生成では書き換えない。Keystatic とポッドキャスト ingest の対象ではない。

**ファイル数:** 5（月〜金で各1つ）。ZIPにまとめない。

**ファイル名の例**（曜日とテーマが分かること）:

```
月曜_平城京と奈良時代のはじまり.mdoc
火曜_聖武天皇と東大寺の大仏.mdoc
水曜_国分寺と仏教のちから.mdoc
木曜_平安京への遷都794年.mdoc
金曜_奈良時代のおわりと平安の扉.mdoc
```

- 先頭に曜日（`月曜`〜`金曜`）
- アンダースコアの後に短いテーマ
- 拡張子 `.mdoc`（Markdoc）
- テーマはその日の焦点を表す（当該テキストの範囲内）

## 各ファイルの構造（推奨）

教材は **YAML frontmatter + Markdoc 本文** とする。ページの見出し・チップは frontmatter から出るので、本文に `# タイトル` や `**テキスト**` 行は書かない。

キャラクター ID（`say` の `character` と `cast` のキー）:

| ID | ぬいぐるみ |
|----|-----------|
| `kuma` | くまぴー |
| `tora` | とらぴー |
| `neko` | ねこぴー |
| `kitsu` | きつぴー |
| `miju` | みじゅぴー |
| `ichi` | いちぴー |
| `nasu` | なすぴー |
| `tako` | たこぴー |
| `ramen` | らーぴー |

隔週ローテーションで **その週に登場する4 ID** は `references/story-rules.md` の表から決める。月曜の frontmatter に `weekCast` として書く（例: `[kuma, tora, neko, kitsu]`）。本文ではその4 ID だけ `say` / `cast` に使う。

月曜:

```mdoc
---
textCode: "540-23"
unit: "平城京・平安京"
weekCast:
  - kuma
  - tora
  - neko
  - kitsu
weekOutline:
  - day: mon
    theme: "平城京と奈良時代のはじまり"
    mode: observation
  - day: tue
    theme: "聖武天皇と東大寺の大仏"
    mode: roleplay
    roles: "聖武天皇と行基"
  # … wed / thu / fri
---

{% scene %}
（場面の地の文・1段落）
{% /scene %}

{% say character="kuma" %}
（発話。かぎ括弧「」は付けない）
{% /say %}
```

火〜金:

```mdoc
---
textCode: "540-23"
unit: "平城京・平安京"
focus: "聖武天皇と東大寺の大仏（745年）"
cast:
  kuma: 聖武天皇
  neko: 行基
---

{% scene %}…{% /scene %}
{% say character="kuma" %}…{% /say %}
```

- **人物体験の日**は `cast` に、その日のぬいぐるみ ID → 歴史人物名を書く。発話は `{% say character="kuma" %}` のように ID だけ指定し、**`say` に役名は書かない**（サイトが `cast` から毎行表示する）。
- **観察の日**は `cast` を省略するか空にする。
- 読者向け注記は `{% say character="neko" note="…" %}` の `note` 属性（発話の外）。

## ユーザーへの提示

1. 5ファイルを書き終えたら、**各ファイルを個別にリンク**する（リポジトリ内相対パスでよい）
2. リンクテキストに **曜日とテーマ** を含める
3. ZIPアーカイブは作らない・渡さない
4. チャットのみで渡す場合（Write不可）: 曜日ごとに見出しを分けて本文を貼る。ファイル添付を **したと偽らない**

- [ ] 人物体験中に丁寧語を使わず、相手をぬいぐるみ名で呼んでいる
- [ ] 人物体験中に、自分が役を演じているというメタ発言や、終了後の感想会がない
- [ ] すべてのボケ・勘違い・ふざけた提案の直後に、別のぬいぐるみが内容へ具体的に反応している

- [ ] 物語・メタ行に特定の塾名が入っていない
- [ ] 捏造した年号・単元がない
- [ ] 発話に「土地・家来・主君」など比喩表の避ける語が残っていない（`story-rules.md` の「ぬいぐるみの比喩」）
