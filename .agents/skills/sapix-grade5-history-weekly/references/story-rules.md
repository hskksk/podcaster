# 物語・会話・キャラクター規約

## 登場キャラクター

ぬいぐるみは次の4人。**4人とも男の子**として描写する。

| 絵文字 | 名前 |
|--------|------|
| 🐻 | くまぴー |
| 🐯 | とらぴー |
| 🐱 | ねこぴー |
| 🦊 | きつぴー |

- **キャラクター確認は不要**。すぐ1週間分を作る
- **一人称**は必ず自分の名前（「くまぴー」「とらぴー」など）。「ぼく」「わたし」「おれ」に置き換えない
- 複数で話すときは「ぼくたち」でもよい
- 女の子っぽい語尾（「〜わよ」「〜かしら」など）は4人とも使わない
- 語尾は「〜だよ」「〜だね」「〜じゃない？」など、親しみやすく男の子らしい口調を中心にする

## 物語の形式

- **子ども向けの物語形式**。各日の会話は十分に長く、**やりとりの往復を増やす**
- ただし **一つ一つの発言は短く自然** に。長い説明台詞や硬い講義調は避ける
- 歴史の重要事項を幅広く扱う: 背景・原因・経過・結果、人物同士の関係、政治の仕組み、文化の特徴など、その単元で押さえるべき事実を省きすぎない
- **SAPIXの学習・入試に役立つ正確さ**を優先する

## 物語の見せ方（毎週ミックス）

| 方式 | 内容 |
|------|------|
| 訪問・観察 | ぬいぐるみたちが歴史の場面を訪ねて案内・観察する |
| なりきり | ぬいぐるみたち自身が歴史上の人物になりきって会話や出来事を演じる |

**毎週、単元に合うよう両方を混ぜる**（日ごとに偏ってもよいが、週内で両方が出ること）。

### なりきりの表記

- ぬいぐるみが歴史上の人物を演じる場合、**各章（各日の物語）でそのぬいぐるみ名の直後に人物名を括弧書きするのは初登場時だけ**  
  例: `🐻くまぴー（聖武天皇）`
- それ以外の歴史上の人物も、**その章で初めて出るとき**は名前に括弧で補足してよい

### 年号の表記

歴史用語・出来事で年号が重要な場合、必ず **`用語（年号）`** 形式（例: 平安京への遷都（794年））。

## ボケとツッコミ

会話のたびにちょこちょこ笑えるよう、短いやりとりの中に自然なボケや反応をこまめに入れる。

好みに合わせて、次のタイプを **偏らせず組み合わせ**、歴史用語や出来事に関連した笑いにする:

1. 言葉の意味を少し勘違いする
2. 食べ物に結びつけたり変な想像をしたりする
3. 張り合う・勝手に競争する・大げさに言う
4. 歴史の話から想像が妙な方向へ脱線する
5. いたずらやふざけた提案をする

**ツッコミ**は鋭く、きつく、皮肉っぽくしない。ボケた相手を責めたり、正解を一言で言い切って笑いを終わらせたりするより、聞いている側が「えっ、そうなの？」「ちがうよ💦」と少し慌てながら、**やさしく説明**する雰囲気にする。💦などの絵文字も自然に使ってよい。

ボケ側は、子どもらしく素朴に勘違い・食べ物・変な想像をふくらませる（例:「天下を取る」→「おいしい？？取りたい！」→「食べものじゃないよ💦 日本を全部自分のものにするくらいの意味だよ！」）。

- 笑いはやさしく、親しみやすく、少しドタバタ
- **ギャグで歴史的事実を誤って覚えさせない**
- 学習の流れを止めず、重要な内容は正確に説明する

## ファイルに書いてよいもの・書いてはいけないもの

### 書いてよいもの

- 物語本文を中心に収録
- 月曜冒頭: 今週のテキスト番号・単元と月〜金のテーマ一覧（短く）
- 各日の見出し（曜日・テーマ）

### 書いてはいけないもの（物語の外の独立コーナー）

- 「まとめ」
- 「今日の受験ポイント」
- 「確認クイズ・3問」
- その他、物語と切り離された要約・問題欄

学びは **物語の自然な流れの中** で伝える。

## 正確性

- 歴史的事実や年号を **捏造しない**
- 教科書・SAPIXテキストと食い違う細部は、一覧・一般的な受験範囲に合わせ、不明な年号を創作しない
- 細かい年号の揺れが想定される箇所（例: 造東大寺大仏発願の年）は、物語中で「テキストの年号に合わせてね」と触れてもよいが、一覧にない年号を断定しない
