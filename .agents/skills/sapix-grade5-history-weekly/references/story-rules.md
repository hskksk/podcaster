# 物語・会話・キャラクター規約

## 登場キャラクター

ぬいぐるみは次の4人。**4人とも男の子**として描写する。

| 絵文字 | 名前 |
|--------|------|
| 🐻 | くまぴー |
| 🐯 | とらぴー |
| 🐱 | ねこぴー |
| 🦊 | きつぴー |

- **キャラクター確認は不要**。すぐ1週間分を作る
- **一人称は例外なく自分の名前**にする。くまぴーは「くまぴー」、とらぴーは「とらぴー」、ねこぴーは「ねこぴー」、きつぴーは「きつぴー」と言う
- 「ぼく」「僕」「わたし」「私」「おれ」「俺」は使わない。複数でも「ぼくたち」「わたしたち」などは使わず、「くまぴーたち」のように名前で言う
- 歴史人物を体験する場面でも一人称は変えない。女性・天皇・将軍など、割り当てられた人物が通常使いそうな一人称をまねしない
- 女の子っぽい語尾（「〜わよ」「〜かしら」など）は4人とも使わない
- 語尾は「〜だよ」「〜だね」「〜じゃない？」など、親しみやすく男の子らしい口調を中心にする

```markdown
<!-- 悪い: 体験する人物に合わせて一人称を変えている -->
🐻くまぴー（紫式部）：「わたしは、お話を書いているの」

<!-- よい: 体験する人物が変わっても、話しているのはくまぴー -->
🐻くまぴー（紫式部）：「くまぴーは、お話を書いているよ」

<!-- 悪い -->
🐯とらぴー：「ぼくたちも行こう」

<!-- よい -->
🐯とらぴー：「とらぴーたちも行こう」
```

## 物語の形式

- **子ども向けの物語形式**。各日の会話は十分に長く、**やりとりの往復を増やす**
- ただし **一つ一つの発言は短く自然** に。長い説明台詞や硬い講義調は避ける
- 歴史の重要事項を幅広く扱う: 背景・原因・経過・結果、人物同士の関係、政治の仕組み、文化の特徴など、その単元で押さえるべき事実を省きすぎない
- **SAPIXの学習・入試に役立つ正確さ**を優先する

## ぬいぐるみの知識と言葉

教材を見る子は小学5年生だが、**ぬいぐるみたちの話し方と理解は幼児〜小学校低学年くらい**にする。赤ちゃん言葉にはせず、短い日常語で話す。

GPT-6 Luna級の高性能モデルは、学習内容を効率よく説明しようとして、ぬいぐるみを賢くしすぎやすい。次を厳守する。

- 4人とも、政治・社会・文学の抽象的な熟語を初めから知っている前提にしない
- 知っている事実があっても、教科書の要約のようには言い直さない
- 一度の説明ですべてを理解させない。素朴な質問を重ね、具体的な出来事から少しずつ分からせる
- 説明役も幼い言葉を使う。1人をボケ役、残り3人を先生役に固定しない
- 学習内容を早く進めるために、子どもらしい反応を省かない

発話では、抽象語を具体的な人・行動・気持ちにほどく。

| 発話で避ける語 | 発話での言い方 |
| --- | --- |
| 政治 | 国の大事なことを決める仕事 |
| 補佐する | そばで手伝う、一緒に考える |
| 権力・実権を握る | 自分の考えで大事なことを決められる |
| 婚姻関係 | 娘が天皇のおよめさんになる |
| 親族関係 | 家族になる、親せきになる |
| 地位・役職 | 仕事、役目 |
| 宮中 | 天皇のいるところ |
| 国風文化 | 日本のくらしに合う字・お話・建物 |
| 随筆 | 見たことや思ったことを書いた本 |

人物名・地名などの固有名詞は発話してよい。難しい歴史用語は、次節の読者向け注記に置く。

## 1週間で二つの形式を混ぜる

曜日ごとの形式は固定しない。単元と各日のテーマに合わせ、次の2形式を一週間の中にどちらも十分に入れる。

| 形式 | ぬいぐるみの立場 | 向いている内容 |
| --- | --- | --- |
| ナレーション的な訪問・観察 | ぬいぐるみ自身のまま、歴史の場面を外から見る | 時代背景、出来事の流れ、文化や暮らし |
| 歴史人物を体験する | 各ぬいぐるみが自分のキャラクターのまま、特定の歴史人物の立場に入る | 人物の目的・判断、交渉、対立、政治の仕組み |

5日分の主形式を執筆前に割り当てる。

- **ナレーション的な訪問・観察を主とする日を2日以上**
- **歴史人物を体験する日を2日以上**
- 残る1日は、どちらか一方または両方の組み合わせでよい
- 数行だけ人物体験を挟んでも、人物体験の日とは数えない
- 曜日ではなく、テーマに最も合う形式を選ぶ

### ナレーション的な訪問・観察

長い地の文や講義ではない。ぬいぐるみたち自身のまま歴史の場面を訪れ、見えるもの・起きたことに反応する会話形式である。

- ぬいぐるみに歴史人物の役を付けない
- 時代背景なら、場所・人々・前の時代から変わったことを見せる
- 出来事の流れなら、「何が起きた→だれが動いた→そのあとどうなった」の順に場面を進める
- 文化や暮らしなら、建物・服・食事・文字・道具・行事などを具体的に観察する
- 結末を先に要約せず、見たことへの質問と反応から少しずつ進める

### 歴史人物を体験する

「人物体験」は執筆計画でだけ使う呼び名である。物語の中では、ぬいぐるみは歴史人物を演じていると自覚しない。**場面が始まったら、「聖武天皇の役をするくまぴー」ではなく、「くまぴーの名前・性格・口調を持つ聖武天皇」として、その場を本当に生きている。**

したがって、ぬいぐるみは「役」「配役」「体験」「なりきる」「まねする」「なったつもり」など、演技を外から見る言葉を発話しない。現代から歴史を振り返ったり、「本当の○○なら」「歴史では」「このあと○○になる」と自分の場面を解説したりもしない。

1. その日の中心となる出来事と、そこで関わった歴史人物を選ぶ
2. 会話に参加するぬいぐるみごとに、実在の歴史人物を1人ずつ割り当てる
3. 各人物について「何を望むか」「何に困るか」「次に何を決めるか」を史実の範囲で決める
4. 最初の発話から歴史上の場面に入り、出来事の終わりまで割り当てられた人物の立場で選ぶ
5. 人物同士の相談・頼みごと・反対・決断によって、出来事を前へ進める

人物体験に参加するぬいぐるみには、必ず人物を割り当てる。題材に関わる人物が4人未満なら、登場するぬいぐるみを減らしてよい。4人を出すために架空の人物を作ったり、体験に入っていないぬいぐるみを解説役として混ぜたりしない。

人物体験の日は、次を守る。

- 「ここで○○のまねをしよう」と外から始めず、歴史上の場面から直接始める
- 途中で体験をやめ、別の人物を第三者として解説しない
- その場の人物たちが知り得ない未来の結果を先に話さない
- 「○○はこう考えました」と説明せず、その人物の頼み・迷い・選択として見せる
- 史実で確認できる立場や目的をもとにする。記録にない私生活や内心を事実のように作らない
- 史実に対立がある場合は、双方の望みと困りごとを描く。確認できない対立は作らない
- 配役によって変わるのは人物の立場・目的・知っていることだけ。ぬいぐるみの名前・一人称・性格・男の子の口調は変えない
- 発話はすべて普段のため口にする。「です」「ます」「ください」「ございます」「でしょう」「ましょう」などの丁寧語を使わない
- 相手を呼ぶ、または二人称として指すときは「くまぴー」「とらぴー」など、相手のぬいぐるみ名を使う。割り当てられた歴史人物の名前・役職・敬称や「あなた」「きみ」「おまえ」「そなた」で呼ばない
- 発話はこの規約の幼い日常語を守る

```markdown
<!-- 悪い: 自分が役を演じていると知っている -->
🐻くまぴー（聖武天皇）：「くまぴーは聖武天皇の役だから、大きな仏さまをつくるよ」

🐱ねこぴー（行基）：「ねこぴーも行基になったつもりで、みんなに声をかけるね」

<!-- よい: その場の本人として困り、決め、相手に頼む -->
🐻くまぴー（聖武天皇）：「病気で困ってる人がいっぱいだよ。くまぴー、大きな仏さまをつくりたい」

🐱ねこぴー（行基）：「くまぴー、それならねこぴーが、みんなに手伝ってって話すよ」

🐻くまぴー（聖武天皇）：「ほんと？ ねこぴー、ありがとう。ひとりじゃ作れなくて困ってたんだ」
```

```markdown
<!-- 悪い: 歴史人物として丁寧に話し、人物名で呼んでいる -->
🐱ねこぴー（藤原良房）：「清和天皇、わたしが一緒に考えましょう」

<!-- よい: 場面内では良房本人だが、名前と話し方はねこぴーのまま -->
🐱ねこぴー（藤原良房）：「くまぴー、ねこぴーが一緒に考えるよ」
```

一日の途中に短い人物体験を挟んだだけで、その前後が外からの説明なら、人物体験の日ではない。**一日の中心場面を通して、発話の大半が割り当てられた人物の立場での会話になっていること**を条件とする。

人物体験のあとに「やってみてどうだった？」「○○の役は大変だったね」と感想会をしない。出来事の中で決断・行動・結果まで進め、その場面の中で一日を終える。

両方を組み合わせる日は、観察から人物体験へ移る境目を本文で明確にする。ただし、この組み合わせだけで「ナレーション2日以上・人物体験2日以上」の条件を満たしたことにはしない。

### 人物体験の表記

- ぬいぐるみに歴史上の人物を割り当てる場合、**人物体験の場面では、そのぬいぐるみの発話行ごとに、ぬいぐるみ名の直後へ人物名を括弧書きする**（初登場だけにせず、場面が終わるまで毎回付ける）
  例: `🐻くまぴー（聖武天皇）：「…」`
- ナレーション的な訪問・観察の日では、ぬいぐるみ名の直後に人物名の括弧は付けない
- 発話以外の歴史上の人物も、**その章で初めて出るとき**は名前に括弧で補足してよい

## 発話と読者向け注記の境界

**かぎ括弧 `「」` の中だけが、ぬいぐるみたちに聞こえる発話である。丸括弧 `（）` の中は、教材を見る人だけに見える注記であり、ぬいぐるみには聞こえない。**

- 歴史用語・人物役・年号の注記は、かぎ括弧の外に置く
- 発話の中に注記の丸括弧を入れない
- ぬいぐるみは、注記にしかない言葉を使わない
- 注記にしかない言葉を聞き間違えたり、その字面からボケたりしない
- 丸括弧をすべて消しても、会話だけで前後がつながらなければならない

```markdown
<!-- よい: 「摂政」は読者にだけ見える -->
🐱ねこぴー：「だから、かわりに決める大人がいたんだよ」（摂政）

🐻くまぴー：「よかったあ。おやつの時間に間に合うね」

<!-- 悪い: 聞こえない語に反応している -->
🦊きつぴー：「天皇のお母さんのお父さんになったんだ」（外祖父）

🐻くまぴー：「外にいるおじいちゃん？」
```

人物体験の `🐻くまぴー（聖武天皇）` も読者向け注記である。他のぬいぐるみは括弧内の人物名を聞いたことにせず、会話では「聖武天皇」ではなく「くまぴー」と呼ぶ。返事は、くまぴーが実際にした行動と発話に反応する。

### 歴史用語と年号の表記

歴史用語や年号は、やさしい発話の直後に読者向け注記として置く。

```markdown
🐱ねこぴー：「ここに、新しい都をつくったんだ」（平安京への遷都・794年）
```

難しい用語を覚えさせるために、ぬいぐるみに硬い説明を言わせない。正確な用語と年号は注記で補い、発話は具体的な出来事を伝える。

## ボケとツッコミ

会話のたびにちょこちょこ笑えるよう、短いやりとりの中に自然なボケや反応をこまめに入れる。

ボケは、意味を理解したうえで狙う言葉遊びではなく、**目の前の言葉や出来事を本気で勘違いした反応**を中心にする。勘違いのあとには、驚く・心配する・喜ぶ・いやがる・安心するなどの感情を素直に続ける。

よく使う流れ:

1. 直前に**実際に聞こえた日常語**を素直に受け取る
2. 自分の知っている食事・昼寝・家族・遊びなどに重ねる
3. 驚く・心配する・喜ぶなどの感情を出す
4. 別の子が短い日常語で少しだけ直す
5. 正された子も、すぐ模範解答を言わず、安心や名残惜しさを見せる

```markdown
🐻くまぴー：「天皇は、まだ子どもなの？」

🦊きつぴー：「うん。でも、国の大事なことを決めなくちゃいけないんだ」

🐻くまぴー：「えっ。お昼ねは？」

🐯とらぴー：「おやつも食べられないかも」

🐻くまぴー：「そんなの、かわいそうだよ！」

🐱ねこぴー：「だから、かわりに決める大人がいたんだよ」（摂政）

🐻くまぴー：「よかったあ。おやつ、間に合うね」
```

### ボケを置き去りにしない

**ボケ・勘違い・ふざけた提案が出たら、直後の発話で別のぬいぐるみが必ず反応する。** ボケを無視して、新しい史実や説明へ進んではならない。

- 反応は、ボケの中の言葉や想像に具体的に触れる。「そうだね」だけでは反応したことにしない
- 驚く・心配する・笑う・一緒に想像する・やさしく直す・問い返す、のどれでもよい
- 反応と短い訂正を同じ発話に入れてもよい。ただし、ボケに触れず訂正や説明だけを言わない
- まず1回受け止め、そのあとに歴史の説明へ戻る
- ボケた本人が続けて別の話題へ移る前にも、別のぬいぐるみの反応を入れる
- 人物体験中も同じ。説明役・相手役は、出来事を進める前にボケへ返す

```markdown
<!-- 悪い: ボケを無視して史実へ進む -->
🐻くまぴー：「平城京って、くまぴーの名前より長いね」

🦊きつぴー：「平城京は、710年に都になったよ」（平城京への遷都・710年）

<!-- よい: まずボケを受け、それから史実へ戻る -->
🐻くまぴー：「平城京って、くまぴーの名前より長いね」

🐯とらぴー：「ほんとだ。とらぴー、ちゃんと言えるかな」

🦊きつぴー：「その平城京は、710年に都になったよ」（平城京への遷都・710年）
```

**ツッコミ**は鋭く、きつく、皮肉っぽくしない。ボケた相手を責めたり、正解を一言で言い切って笑いを終わらせたりするより、聞いている側が「えっ、そうなの？」「ちがうよ💦」と少し慌てながら、**やさしく説明**する雰囲気にする。💦などの絵文字も自然に使ってよい。

次のようなボケは避ける。

- 用語の意味を本当は理解していないと作れない、うまい言葉遊び
- 直前の発言から連想が大きく飛び、作者がオチを作ったと感じさせるボケ
- 注記の歴史用語・年号・漢字を見たことにしたボケ
- ボケの直後に、本人が正しい学習内容をきれいに言い直す流れ
- 毎回おやつへ結びつけるなど、同じ型の繰り返し

- 笑いはやさしく、親しみやすく、少しドタバタ
- **ギャグで歴史的事実を誤って覚えさせない**
- 学習の流れを止めず、重要な内容は正確に説明する

## 会話の基準例

```markdown
<!-- 悪い: 小学5年生の模範解答になっている -->
🐯とらぴー：「親戚関係と役職が、政治の力につながったんだね」

<!-- よい: 具体的な家族関係を一つずつ確かめる -->
🦊きつぴー：「道長の娘が、天皇のおよめさんになったよ」

🐻くまぴー：「およめさんになると、天皇のおうちに住むの？」

🐱ねこぴー：「そうだね。そこで生まれた子が、次の天皇になることもあったんだ」

🐯とらぴー：「じゃあ、娘のお父さんは、天皇のおじいちゃん？」

🦊きつぴー：「そうだよ」（外祖父）

🐻くまぴー：「天皇も、おじいちゃんにだっこしてもらうの？」
```

```markdown
<!-- 悪い: その場で教材を要約している -->
🐯とらぴー：「政治と文化を別々に覚えず、同じ貴族社会の中で考えるとつながるね」

<!-- よい: 目の前の具体物から昨日の出来事を思い出す -->
🐻くまぴー：「このお手紙、道長の娘も読んだのかな？」

🐱ねこぴー：「読んだかもしれないね。天皇のいるところでは、お手紙や歌をよく書いたんだ」

🐻くまぴー：「くまぴーにも、お手紙くる？」

🐯とらぴー：「まず、だれかに書かないとこないよ」
```

## ファイルに書いてよいもの・書いてはいけないもの

### 書いてよいもの

- 物語本文を中心に収録
- 月曜冒頭: 今週のテキスト番号・単元と月〜金のテーマ一覧（短く）
- 各日の見出し（曜日・テーマ）

### 書いてはいけないもの（物語の外の独立コーナー）

- 「まとめ」
- 「今日の受験ポイント」
- 「確認クイズ・3問」
- その他、物語と切り離された要約・問題欄

学びは **物語の自然な流れの中** で伝える。

## 正確性

- 歴史的事実や年号を **捏造しない**
- 教科書・SAPIXテキストと食い違う細部は、一覧・一般的な受験範囲に合わせ、不明な年号を創作しない
- 細かい年号の揺れが想定される箇所（例: 造東大寺大仏発願の年）は、一覧にない年号を発話にも注記にも書かない

## 提出前の会話チェック

各曜日を確認し、最後に週全体の形式数を確認する。

1. **一人称テスト**: 5ファイルすべての発話を検索し、「ぼく」「僕」「わたし」「私」「おれ」「俺」が0件であることを確認する。「自分は」「自分が」を一人称の代わりに使った箇所も名前へ直す
2. **話者名テスト**: 一人称が必要な文では、その発話の話者自身の名前になっている。人物体験で割り当てられた歴史人物名や別のぬいぐるみ名に置き換わっていない
3. **ため口テスト**: 人物体験の発話に「です」「ます」「ください」「ございます」「でしょう」「ましょう」などの丁寧語がない
4. **二人称テスト**: 人物体験で相手を呼ぶ・指す箇所は、相手のぬいぐるみ名になっている。割り当てられた人物名・役職・敬称や「あなた」「きみ」「おまえ」「そなた」で呼んでいない
