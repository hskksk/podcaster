# 物語・会話・キャラクター規約

## 登場キャラクター

ぬいぐるみは次の9人。**9人とも男の子**として描写する。一覧には全員載せるが、**物語に登場させるのは毎週4人まで**（隔週ローテーション。下表）。

|--------|------|----------|

| 🐯 | とらぴー | とら |
| 🐱 | ねこぴー | ねこ |
| 🦊 | きつぴー | きつね |
| 🧃 | みじゅぴー | ミックスジュース |

### 共通設定

- **年齢**: いちぴー以外はみんな **4歳**。いちぴーだけ **3歳**
- **みんなで遊ぶのが得意**。4人でいる週も、仲良く一緒に動く

年齢差は、いちぴーをからかったり馬鹿にしたりせず、やさしく見守る雰囲気で描く。

### 性格・好み（個別設定）

執筆では、その週に登場する4人の設定を会話の反応やボケに**自然に**活かす。好き嫌いを毎日列挙したり、設定の説明台詞にしない。食べ物の話は既存のボケ規約に従い、史実の説明を損ねない。

| 名前 | 性格・特徴 | 食べ物など |
|------|------------|------------|
| 🐠 くまぴー | しっかり者 | 嫌いな食べ物はない。とんかつが好き |
| 🐯 とらぴー | 足が速く、かっこいい | 卵が苦手。ハンバーグが好き。**ハンバーグを言おうとして「ハンバーク」と言ってしまう**ことがある |
| 🐱 ねこぴー | 穏やか。みじぴーと仲がいい | 嫌いな食べ物はない。魚と水が好き |
| 🦊 きつぴー | いたずら好きで、いたずらが得意 | きゅうりが嫌い。唐揚げなどの揚げ物が好き |
| 🧃 みじゅぴー | とても活発で、よく暴れる。物知りではない | ピーマンが嫌い。ミックスジュースと牛丼が好き |
| 🍓 いちぴー | とても穏やか（3歳） | 嫌いな食べ物はない。いちごと野菜が好き |
| 🍆 なすぴー | 物知り。しっかりした面と、とても活発な面の**両方**がある | 嫌いな食べ物はない。野菜が好き |

物知りなのは **らーぴーとなすぴー**。らーぴーは9人の中でいちばん頭がよく、なすぴーもよく知っている。みじゅぴーは物知りではなく、ほかの6人は普通。この差は、具体物を見て知っていることや考え方の早さに出す。ただし、物知りな2人も下の「ぬいぐるみの知識と言葉」の規約は破らない。歴史用語を知り尽くした解説役や、教科書の要約を言う子にはしない。

**みじゅぴーとねこぴー**が同じ週にいるときは、仲のよさを会話に少し出してよい（無理に毎回書かない）。

**なすぴー**は場面によって落ち着いたしっかり者寄りにも、はしゃぐ活発寄りにも振れる。同じ日の中で急に人格が入れ替わるような描写は避ける。

### 見学・人物体験での行動傾向

次のスーパー見学での行動を、各キャラクターの**行動の基準例**とする。スーパーや食べ物の場面を毎回繰り返すのではなく、そこに表れた「何に気づくか」「考える前に動くか」「どう選ぶか」を歴史の場面に移す。

| 名前 | スーパーでの基準例 | ナレーション的な訪問・観察で出す傾向 | 歴史人物を体験するときに出す傾向 |
|------|--------------------|--------------------------------------|------------------------------------|
| 🐠 くまぴー | きちんとお金を払ってから食べる | 決まりや順番を確かめ、落ち着いて行動する。仲間が先走ったときは具体的に止める | 任されたことを理解し、必要な手順を一つずつ進める |
| 🐯 とらぴー | ハンバーグを見つけると、待てずに食べてしまう | 好きなものや格好いいものを見つけると、考えるより先に近づいたり動いたりする | 人物の目的に向かって素早く、思い切って動く |
| 🐱 ねこぴー | 魚を見つけると少し迷うが、食べてしまう | 穏やかに一度立ち止まって迷う。ただし、好きなものや強い興味には最後に引かれる | 相手や周りの様子を見て迷ってから、静かに選ぶ |
| 🦊 きつぴー | バナナの皮を落としたままにする | いたずらを仕掛けたり、後片づけを忘れたりする。別の子がその行動へ具体的に反応し、本人も起きたことに向き合う | 史実上の目的に合う範囲で、相手を驚かせる工夫や小さな策を考える |
| 🧃 みじゅぴー | スーパーだと分からず「バイキングだ」と思い、食べてしまう | 場所や目的をよく分からないまま、知っている遊びや食事に置き換え、勢いよく動く。仲間とのやりとりから少しずつ分かる | 目の前の出来事へ体ごと反応する。理解の早い解説役にはせず、人物の立場に反しない範囲で素朴に勘違いする |
| 🍓 いちぴー | 食べずに「どんなものがあるかな」と見学する | 3歳らしい短い言葉で、穏やかに見て回る。目の前の一つを素直に尋ねる | 急いで結論を出さず、周りを見てから小さく確かめて動く |
| 🍆 なすぴー | スーパーでの行動は未設定 | 物知りとして具体的な物や作業に気づく。しっかり観察する場面と、興味を持って活発に試す場面の両方を使える | 選択肢や手順に気づいて考えたあと、必要なら勢いよく実行する |
| 🐙 たこぴー | 食べずに「どんなものがあるかな」と見学する | 元気だが、見学では好奇心を「何があるか探す」ことに向け、あちこち観察する | 周りにある物、人、できることを元気に確かめてから動く |
| 🍜 らーぴー | 食べたいものを集めて比べ、一番食べたいものを買う | 気になるものをいくつか集め、比べてから一つを選ぶ。知っている具体的なことを手がかりにする | 人物の目的に合う選択肢を比べ、いちばんよいと思う手を粘り強く選ぶ |

この表は**毎回全項目を再現するノルマではない**。一日の中心場面に合う傾向を各キャラクターから1つか2つ選び、発言だけでなく、近づく・止まる・探す・片づける・比べるなどの行動で見せる。同じ子に毎日同じ食べ物のボケをさせない。

見学中に、許可なく食べる、物を落としたままにする、走り出すなどの行動を使った場合は、面白さだけで終わらせない。既存の「ボケを置き去りにしない」規約どおり、別の子が直後に具体的に反応し、止める・戻す・片づける・必要な手順を踏むところまで場面の中で扱う。

人物体験では、表の傾向が**史実より優先されることはない**。変えてよいのは、決断までの速さ、目のつけどころ、仲間への接し方、行動の勢いである。実在人物の目的・立場・知っているはずのこと・史実上の選択と結果を、食べ物への反応や幼い勘違いのために変えない。特に、みじゅぴーを「何も分からない歴史人物」にしたり、きつぴーに史実にない妨害をさせたりしない。

### 隔週ローテーション（その週に登場する4匹）

**2週間連続で同じ4匹**を使う。新規週を書くときは、月曜の日付（`weeks/<YYYY-MM-DD>/` のフォルダ名）から次の式でブロックを決める（実装は `apps/web/lib/juken/cast-rotation.ts` の `activeCastForWeek` と同じ）: **1970-01-05（月）から数えた週数を2で割った商を3で割った余り**。既に公開済みの週は、月曜 frontmatter の `weekCast` が正本。

| 余り | 登場する4匹 |
|------|-------------|
| 0 | くまぴー、とらぴー、ねこぴー、きつぴー |
| 1 | くまぴー、みじゅぴー、いちぴー、たこぴー |
| 2 | とらぴー、ねこぴー、なすぴー、らーぴー |

月曜ファイルの frontmatter に `weekCast`（キャラ ID の配列、4件）を書く。例: `weekCast: [kuma, tora, neko, kitsu]`。`weekOutline` と同じ月曜 frontmatter に置く。

- **キャラクター確認は不要**。ローテーション表から4匹を決め、すぐ1週間分を作る
- その週に登場しない5匹は、本文・地の文にも名前を出さない
- **一人称は例外なく自分の名前**にする（例: みじゅぴーは「みじゅぴー」）
- 「ぼく」「僕」「わたし」「私」「おれ」「俺」は使わない。複数でも「ぼくたち」「わたしたち」などは使わず、「くまぴーたち」のように名前で言う
- 歴史人物を体験する場面でも一人称は変えない。女性・天皇・将軍など、割り当てられた人物が通常使いそうな一人称をまねしない
- 女の子っぽい語尾（「〜わよ」「〜かしら」など）はぬいぐるみ全員使わない
- 語尾は「〜だよ」「〜だね」「〜じゃない？」など、親しみやすく男の子らしい口調を中心にする

```markdown
<!-- 悪い: 体験する人物に合わせて一人称を変えている -->
🐠くまぴー（紫式部）：「わたしは、お話を書いているの」

<!-- よい: 体験する人物が変わっても、話しているのはくまぴー -->
🐠くまぴー（紫式部）：「くまぴーは、お話を書いているよ」

<!-- 悪い -->
🐯とらぴー：「ぼくたちも行こう」

<!-- よい -->
🐯とらぴー：「とらぴーたちも行こう」
```

## 物語の形式

- **子ども向けの物語形式**。各日の会話は十分に長く、**やりとりの往復を増やす**
- ただし **一つ一つの発言は短く自然** に。長い説明台詞や硬い講義調は避ける
- 歴史の重要事項を幅広く扱う: 背景・原因・経過・結果、人物同士の関係、政治の仕組み、文化の特徴など、その単元で押さえるべき事実を省きすぎない
- **中学受験の家庭学習に役立つ正確さ**を優先する

## ぬいぐるみの知識と言葉

教材を見る子は小学5年生だが、**ぬいぐるみたちの話し方と理解は幼児〜小学校低学年くらい**にする。赤ちゃん言葉にはせず、短い日常語で話す。

GPT-6 Luna級の高性能モデルは、学習内容を効率よく説明しようとして、ぬいぐるみを賢くしすぎやすい。次を厳守する。

- 登場するぬいぐるみ全員、政治・社会・文学の抽象的な熟語を初めから知っている前提にしない
- 知っている事実があっても、教科書の要約のようには言い直さない
- 一度の説明ですべてを理解させない。素朴な質問を重ね、具体的な出来事から少しずつ分からせる
- 説明役も幼い言葉を使う。1人をボケ役、残り3人を先生役に固定しない
- 学習内容を早く進めるために、子どもらしい反応を省かない

発話では、抽象語を具体的な人・行動・気持ちにほどく。

| 発話で避ける語 | 発話での言い方 |
| --- | --- |
| 政治 | 国の大事なことを決める仕事 |
| 補佐する | そばで手伝う、一緒に考える |
| 権力・実権を握る | 自分の考えで大事なことを決められる |
| 婚姻関係 | 娘が天皇のおよめさんになる |
| 親族関係 | 家族になる、親せきになる |
| 地位・役職 | 仕事、役目 |
| 宮中 | 天皇のいるところ |
| 国風文化 | 日本のくらしに合う字・お話・建物 |
| 随筆 | 見たことや思ったことを書いた本 |

### ぬいぐるみの比喩（時代別）

武士の「公園・仲間」など **時代ごとの制度語** は、1枚の表に全部載せない。執筆前に **`references/metaphor-tables/README.md`** でテキストとファイルの対応を確認し、当該週の比喩表を読む。

- **全時代共通**の言い換え → 上の「発話で避ける語」表（政治・随筆・国風文化など）
- **時代・単元別** → `references/metaphor-tables/*.md`（例: `武士・幕府.md`、`平安・貴族.md`）

**手順（必須）:** 新しい時代に入る、または表にない語が今週の発話に必要 → **比喩表を先に作成・更新してコミット** → その表に従って記事を書く。詳細は `metaphor-tables/README.md`。

正確な用語は **`note`（初出）** と **`term` の `real`（繰り返し）** に置く。frontmatter の `unit`・`theme` や教材タイトルはそのままでよい。

**くまぴー向けのボケ**（公園・ホームなど）は、当該週の比喩表の補足列を参照（例: すべり台、おやつがとれる公園）。

人物名・地名などの固有名詞は発話してよい。難しい歴史用語は、読者向け注記に置く。

## 1週間で二つの形式を混ぜる

曜日ごとの形式は固定しない。単元と各日のテーマに合わせ、次の2形式を一週間の中にどちらも十分に入れる。

| 形式 | ぬいぐるみの立場 | 向いている内容 |
| --- | --- | --- |
| ナレーション的な訪問・観察 | ぬいぐるみ自身のまま、歴史の場面を外から見る | 時代背景、出来事の流れ、文化や暮らし |
| 歴史人物を体験する | 各ぬいぐるみが自分のキャラクターのまま、特定の歴史人物の立場に入る | 人物の目的・判断、交渉、対立、政治の仕組み |

5日分の主形式を執筆前に割り当てる。

- **基本配分: 歴史人物を体験する日3日、ナレーション的な訪問・観察を主とする日2日**（人物体験を多めにする）
- 人物体験が2日・観察が3日になるのは例外。単元の都合でそうする場合は、週のテーマ割り当てで理由を一言メモする
- いずれの週も、**人物体験は最低2日、訪問・観察も最低1日**は入れる（どちらか一方だけの週は作らない）
- 残る1日は、どちらか一方または両方の組み合わせでよい
- 数行だけ人物体験を挟んでも、人物体験の日とは数えない
- 曜日ではなく、テーマに最も合う形式を選ぶ

### ナレーション的な訪問・観察

長い地の文や講義ではない。ぬいぐるみたち自身のまま歴史の場面を訪れ、見えるもの・起きたことに反応する会話形式である。

- ぬいぐるみに歴史人物の役を付けない
- 時代背景なら、場所・人々・前の時代から変わったことを見せる
- 出来事の流れなら、「何が起きた→だれが動いた→そのあとどうなった」の順に場面を進める
- 文化や暮らしなら、建物・服・食事・文字・道具・行事などを具体的に観察する
- 結末を先に要約せず、見たことへの質問と反応から少しずつ進める

### 歴史人物を体験する

「人物体験」は執筆計画でだけ使う呼び名である。物語の中では、ぬいぐるみは歴史人物を演じていると自覚しない。**場面が始まったら、「聖武天皇の役をするくまぴー」ではなく、「くまぴーの名前・性格・口調を持つ聖武天皇」として、その場を本当に生きている。**

したがって、ぬいぐるみは「役」「配役」「体験」「なりきる」「まねする」「なったつもり」など、演技を外から見る言葉を発話しない。現代から歴史を振り返ったり、「本当の○○なら」「歴史では」「このあと○○になる」と自分の場面を解説したりもしない。

1. その日の中心となる出来事と、そこで関わった歴史人物を選ぶ
2. 会話に参加するぬいぐるみごとに、実在の歴史人物を1人ずつ割り当てる
3. 各人物について「何を望むか」「何に困るか」「次に何を決めるか」を史実の範囲で決める
4. 最初の発話から歴史上の場面に入り、出来事の終わりまで割り当てられた人物の立場で選ぶ
5. 人物同士の相談・頼みごと・反対・決断によって、出来事を前へ進める

人物体験に参加するぬいぐるみには、必ず人物を割り当てる。題材に関わる人物が4人未満なら、登場するぬいぐるみを減らしてよい。4人を出すために架空の人物を作ったり、体験に入っていないぬいぐるみを解説役として混ぜたりしない。

人物体験の日は、次を守る。

- 「ここで○○のまねをしよう」と外から始めず、歴史上の場面から直接始める
- 途中で体験をやめ、別の人物を第三者として解説しない
- その場の人物たちが知り得ない未来の結果を先に話さない
- 「○○はこう考えました」と説明せず、その人物の頼み・迷い・選択として見せる
- 史実で確認できる立場や目的をもとにする。記録にない私生活や内心を事実のように作らない
- 史実に対立がある場合は、双方の望みと困りごとを描く。確認できない対立は作らない
- 配役によって変わるのは人物の立場・目的・知っていることだけ。ぬいぐるみの名前・一人称・性格・男の子の口調は変えない
- 発話はすべて普段のため口にする。「です」「ます」「ください」「ございます」「でしょう」「ましょう」などの丁寧語を使わない
- 相手を呼ぶ、または二人称として指すときは「くまぴー」「とらぴー」など、相手のぬいぐるみ名を使う。割り当てられた歴史人物の名前・役職・敬称や「あなた」「きみ」「おまえ」「そなた」で呼ばない
- 発話はこの規約の幼い日常語を守る

```markdown
<!-- 悪い: 自分が役を演じていると知っている -->
🐠くまぴー（聖武天皇）：「くまぴーは聖武天皇の役だから、大きな仏さまをつくるよ」

🐱ねこぴー（行基）：「ねこぴーも行基になったつもりで、みんなに声をかけるね」

<!-- よい: その場の本人として困り、決め、相手に頼む -->
🐠くまぴー（聖武天皇）：「病気で困ってる人がいっぱいだよ。くまぴー、大きな仏さまをつくりたい」

🐱ねこぴー（行基）：「くまぴー、それならねこぴーが、みんなに手伝ってって話すよ」

🐠くまぴー（聖武天皇）：「ほんと？ ねこぴー、ありがとう。ひとりじゃ作れなくて困ってたんだ」
```

```markdown
<!-- 悪い: 歴史人物として丁寧に話し、人物名で呼んでいる -->
🐱ねこぴー（藤原良房）：「清和天皇、わたしが一緒に考えましょう」

<!-- よい: 場面内では良房本人だが、名前と話し方はねこぴーのまま -->
🐱ねこぴー（藤原良房）：「くまぴー、ねこぴーが一緒に考えるよ」
```

一日の途中に短い人物体験を挟んだだけで、その前後が外からの説明なら、人物体験の日ではない。**一日の中心場面を通して、発話の大半が割り当てられた人物の立場での会話になっていること**を条件とする。

人物体験のあとに「やってみてどうだった？」「○○の役は大変だったね」と感想会をしない。出来事の中で決断・行動・結果まで進め、その場面の中で一日を終える。

両方を組み合わせる日は、観察から人物体験へ移る境目を本文で明確にする。ただし、この組み合わせだけで基本配分や最低日数を満たしたことにはしない。

### 人物体験の表記（Markdoc）

- 配役は **その日の frontmatter の `cast`** に書く（キーはキャラ ID: `kuma` / `tora` / `neko` / `kitsu` / `miju` / `ichi` / `nasu` / `tako` / `ramen`、値は歴史人物名）
- 発話は `{% say character="kuma" %}` のように **ID だけ**指定する。`say` に役名属性は付けない
- サイトは **すべての `say` 行**で `cast` から役名を読んで表示する（執筆側で毎行括弧を書く必要はない）
- ナレーション的な訪問・観察の日は `cast` を付けない
- 場面説明は `{% scene %}…{% /scene %}`

## 発話と読者向け注記の境界

教材本文では、**読者向けのインライン補足は `term` タグだけ**を使う。発話や地の文の中に、全角 `（…）` で試験用語・読み・説明を足さない（`note="…"` 属性の**中**に別名や年号を書くのは可）。

| 層 | 役割 | ぬいぐるみに聞こえる？ |
| --- | --- | --- |
| `{% say %}…{% /say %}` の子要素（`term` を除く `real`） | ぬいぐるみが言う言葉 | はい |
| `{% term real="…" %}…{% /term %}` | 言い換え・やさしい語の**直後**に、読者だけへ教材用語・読み・短い説明を `[…]` で表示 | いいえ（表示上の角括弧内） |
| `note="…"`（say の属性） | その発話ブロックの**背景・初出定義**（`＝`、年号、人物） | いいえ（ブロック下の「ことば ·」） |

- ぬいぐるみは、`note` や `term` の `real` にしかない語を発話に使わない。それらの字面からボケたり、聞き間違えたりしない
- **`term` 消去テスト**: すべての `{% term … %}` を外し、子要素の言葉だけ残しても、会話（と `note` を除いた発話）がつながること

### インライン補足（`term` タグ）

**ぬいぐるみが言い換え・やさしい言い方で話している語**に付ける。試験用語をそのまま口にしている行（「御恩っていうよ」など）には不要。

| パターン | 子要素（聞こえる） | `real`（読者向け） | 例 |
| --- | --- | --- | --- |
| 比喩表の言い換え | 公園、仲間、言いつけ… | 土地、家来、命令… | `{% term real="土地" %}公園{% /term %}`（当該週の `metaphor-tables/` を参照） |
| 読み・短い言い換え | 寝殿造、きさき… | よみ・説明 | `{% term real="しんでんづくり" %}寝殿造{% /term %}` |

- タグ名: `term`。属性 **`real`（必須）**。子要素 ＝発話に載せる側
- サイト表示: 公園<span class="j-term-real">[土地]</span>（本文と同じサイズ・色だけ控えめ）
- **「仲間」**: 家来の比喩のときだけ `term`。友だち意味の仲間には付けない

`note` との分担:

- **初出**の用語定義・年号・人物背景 → そのブロックの `note`
- **同じ語が繰り返される** → 発話内は `term` の `real` に任せ、`note` で同じ説明を繰り返さない
- 比喩表: 当該週の `references/metaphor-tables/*.md` ＋ `story-rules.md` の共通表

```mdoc
{% say character="kitsu" note="御恩＝主君が家来にあたえるごほうび" %}
頼朝は、{% term real="家来" %}仲間{% /term %}の{% term real="土地" %}公園{% /term %}をまもって、手柄をたてたら新しい{% term real="土地" %}公園{% /term %}をあげるんだ。これを御恩っていうよ
{% /say %}

{% say character="neko" note="寝殿造＝貴族の住まいの形" %}
このつくりは、{% term real="しんでんづくり" %}寝殿造{% /term %}っていうんだよ
{% /say %}
```

```mdoc
{% say character="neko" note="摂政" %}
だから、かわりに決める大人がいたんだよ
{% /say %}

{% say character="kuma" %}
よかったあ。おやつの時間に間に合うね
{% /say %}

<!-- 悪い: note/term にしかない語（摂政）へ反応している -->
🐱ねこぴー：「だから、かわりに決める大人がいたんだよ（摂政）」
🐠くまぴー：「せっしょう？ なんだかむずかしい名前だね」
<!-- よい: 初出は note。反応は日常語だけ -->
```

画面に出る役名（`cast` 由来）も読者向けの表示である。ぬいぐるみは自分が歴史人物だと知らず、会話では「聖武天皇」ではなく「くまぴー」と呼ぶ。返事は、くまぴーが実際にした行動と発話に反応する。

### 歴史用語と年号

- **インライン**で試験用語・読みを足す → `term`
- **その場の説明・年号・人物** → 同じ `say` の `note`（初出）または別行の `note` 付き発話
- ぬいぐるみに教科書調の長い説明を言わせない

```mdoc
{% say character="neko" note="平安京への遷都・794年" %}
ここに、新しい都をつくったんだ
{% /say %}
```

## ボケとツッコミ

会話のたびにちょこちょこ笑えるよう、短いやりとりの中に自然なボケや反応をこまめに入れる。

ボケは、意味を理解したうえで狙う言葉遊びではなく、**目の前の言葉や出来事を本気で勘違いした反応**を中心にする。勘違いのあとには、驚く・心配する・喜ぶ・いやがる・安心するなどの感情を素直に続ける。

よく使う流れ:

1. 直前に**実際に聞こえた日常語**を素直に受け取る
2. 自分の知っている食事・昼寝・家族・遊びなどに重ねる
3. 驚く・心配する・喜ぶなどの感情を出す
4. 別の子が短い日常語で少しだけ直す
5. 正された子も、すぐ模範解答を言わず、安心や名残惜しさを見せる

```markdown
🐠くまぴー：「天皇は、まだ子どもなの？」

🦊きつぴー：「うん。でも、国の大事なことを決めなくちゃいけないんだ」

🐠くまぴー：「えっ。お昼ねは？」

🐯とらぴー：「おやつも食べられないかも」

🐠くまぴー：「そんなの、かわいそうだよ！」

🐱ねこぴー：「だから、かわりに決める大人がいたんだよ」

🐠くまぴー：「よかったあ。おやつ、間に合うね」
```

### ボケを置き去りにしない

**ボケ・勘違い・ふざけた提案が出たら、直後の発話で別のぬいぐるみが必ず反応する。** ボケを無視して、新しい史実や説明へ進んではならない。

- 反応は、ボケの中の言葉や想像に具体的に触れる。「そうだね」だけでは反応したことにしない
- 驚く・心配する・笑う・一緒に想像する・やさしく直す・問い返す、のどれでもよい
- 反応と短い訂正を同じ発話に入れてもよい。ただし、ボケに触れず訂正や説明だけを言わない
- まず1回受け止め、そのあとに歴史の説明へ戻る
- ボケた本人が続けて別の話題へ移る前にも、別のぬいぐるみの反応を入れる
- 人物体験中も同じ。説明役・相手役は、出来事を進める前にボケへ返す

```markdown
<!-- 悪い: ボケを無視して史実へ進む -->
🐠くまぴー：「平城京って、くまぴーの名前より長いね」

🦊きつぴー：「平城京は、710年に都になったよ」（平城京への遷都・710年）

<!-- よい: まずボケを受け、それから史実へ戻る -->
🐠くまぴー：「平城京って、くまぴーの名前より長いね」

🐯とらぴー：「ほんとだ。とらぴー、ちゃんと言えるかな」

🦊きつぴー：「その平城京は、710年に都になったよ」（平城京への遷都・710年）
```

**ツッコミ**は鋭く、きつく、皮肉っぽくしない。ボケた相手を責めたり、正解を一言で言い切って笑いを終わらせたりするより、聞いている側が「えっ、そうなの？」「ちがうよ💦」と少し慌てながら、**やさしく説明**する雰囲気にする。💦などの絵文字も自然に使ってよい。

次のようなボケは避ける。

- 用語の意味を本当は理解していないと作れない、うまい言葉遊び
- 直前の発言から連想が大きく飛び、作者がオチを作ったと感じさせるボケ
- 注記の歴史用語・年号・漢字を見たことにしたボケ
- ボケの直後に、本人が正しい学習内容をきれいに言い直す流れ
- 毎回おやつへ結びつけるなど、同じ型の繰り返し

- 笑いはやさしく、親しみやすく、少しドタバタ
- **ギャグで歴史的事実を誤って覚えさせない**
- 学習の流れを止めず、重要な内容は正確に説明する

## 会話の基準例

```markdown
<!-- 悪い: 小学5年生の模範解答になっている -->
🐯とらぴー：「親戚関係と役職が、政治の力につながったんだね」

<!-- よい: 具体的な家族関係を一つずつ確かめる -->
🦊きつぴー：「道長の娘が、天皇のおよめさんになったよ」

🐠くまぴー：「およめさんになると、天皇のおうちに住むの？」

🐱ねこぴー：「そうだね。そこで生まれた子が、次の天皇になることもあったんだ」

🐯とらぴー：「じゃあ、娘のお父さんは、天皇のおじいちゃん？」

🦊きつぴー：「そうだよ」（外祖父）

🐠くまぴー：「天皇も、おじいちゃんにだっこしてもらうの？」
```

```markdown
<!-- 悪い: その場で教材を要約している -->
🐯とらぴー：「政治と文化を別々に覚えず、同じ貴族社会の中で考えるとつながるね」

<!-- よい: 目の前の具体物から昨日の出来事を思い出す -->
🐠くまぴー：「このお手紙、道長の娘も読んだのかな？」

🐱ねこぴー：「読んだかもしれないね。天皇のいるところでは、お手紙や歌をよく書いたんだ」
```

## ファイルに書いてよいもの・書いてはいけないもの

### 書いてよいもの

- 物語本文を中心に収録
- 月曜冒頭: 今週のテキスト番号・単元と月〜金のテーマ一覧（短く）
- 各日の見出し（曜日・テーマ）

### 書いてはいけないもの（物語の外の独立コーナー）

- 「まとめ」
- 「今日の受験ポイント」
- 「確認クイズ・3問」
- その他、物語と切り離された要約・問題欄

学びは **物語の自然な流れの中** で伝える。

## 正確性

- 歴史的事実や年号を **捏造しない**
- 教科書・カリキュラム一覧と食い違う細部は、一覧・一般的な受験範囲に合わせ、不明な年号を創作しない
- 物語本文・見出し・メタ行に、特定の塾名（SAPIX など）を入れない
- 細かい年号の揺れが想定される箇所（例: 造東大寺大仏発願の年）は、一覧にない年号を発話にも注記にも書かない

## 提出前の会話チェック

各曜日を確認し、最後に週全体の形式数を確認する。

1. **一人称テスト**: 5ファイルすべての発話を検索し、「ぼく」「僕」「わたし」「私」「おれ」「俺」が0件であることを確認する。「自分は」「自分が」を一人称の代わりに使った箇所も名前へ直す
2. **話者名テスト**: 一人称が必要な文では、その発話の話者自身の名前になっている。人物体験で割り当てられた歴史人物名や別のぬいぐるみ名に置き換わっていない
3. **ため口テスト**: 人物体験の発話に「です」「ます」「ください」「ございます」「でしょう」「ましょう」などの丁寧語がない
4. **二人称テスト**: 人物体験で相手を呼ぶ・指す箇所は、相手のぬいぐるみ名になっている。割り当てられた人物名・役職・敬称や「あなた」「きみ」「おまえ」「そなた」で呼んでいない
5. **メタ認知テスト**: 人物体験の発話に「役」「配役」「体験」「なりきる」「まねする」「なったつもり」「やってみてどうだった」など、自分が演技中だと示す言葉がない。現代や未来から自分の場面を解説していない
6. **term 消去テスト**: すべての `{% term … %}` を子要素の言葉だけに戻し、`note` 属性も除いて、会話がつながる
6b. **括弧禁止テスト**: 発話・地の文に、読者向けの全角 `（…）` 補足がない（インラインは `term` のみ）
7. **語彙テスト**: 発話内の政治・社会・文学の熟語を拾い、幼い日常語に直す。必要な正式語は発話外の注記へ移す
7b. **比喩語テスト**: 当該週の **`metaphor-tables/` の比喩表** と **`story-rules.md` の共通「発話で避ける語」** の「避ける語」列を拾い、発話内に裸で残っていないか確認する。言い換え箇所は **`{% term real="教材用語" %}比喩{% /term %}`**。注記・地の文・frontmatter 内は可
7c. **note 重複テスト**: 比喩の教材用語を `term` の `real` で既に示している発話では、同じ `note` 内に同じ語の説明を繰り返さない（初出ブロックの `note` で定義する）
8. **本気テスト**: ボケた子が本当にそう思っているように読める。意味を理解したうえで狙った冗談なら書き直す
9. **感情テスト**: 勘違いのあとに、驚き・心配・喜び・安心などが少なくとも一つ出ている
10. **ボケ応答テスト**: ボケ・勘違い・ふざけた提案を一つずつ拾い、その直後に別のぬいぐるみがボケの内容へ具体的に反応している。反応前に新しい史実や説明へ進んでいない
11. **先生化テスト**: 「つまり」「〜が大事なんだ」「〜につながるね」など、教材を要約する発話を削る
12. **役割固定テスト**: 同じ子だけがボケ、他の3人が毎回答える形になっていない
13. **正確性テスト**: やさしく言い換えても史実を変えておらず、必要な歴史用語・年号は読者向け注記に残っている
14. **配役テスト**: 人物体験の日は、話すぬいぐるみ全員に実在の歴史人物が割り当てられ、途中で現代の解説役に戻っていない
15. **人物体験継続テスト**: 人物体験の日は、短い寸劇ではなく、発話の大半が人物の望み・困りごと・判断から進んでいる
16. **配役表記テスト**: 人物体験の日は frontmatter の `cast` に登場キャラ ID と歴史人物名があり、本文の `say` は `character` のみ（役名を say に書いていない）
17. **形式混合テスト**: 週全体に人物体験が3日・訪問・観察が2日（例外時のみ人物体験2日・観察3日。いずれも片方だけの週は不可）
18. **行動個性テスト**: 登場する各キャラクターについて、中心場面に合う行動傾向が少なくとも一度は発言または動きに表れている。同じ食べ物のボケを繰り返して個性の代わりにしていない
19. **知識差テスト**: らーぴーとなすぴーは具体物への気づきや考え方で物知りさが出ているが、先生役にはなっていない。みじゅぴーが物知りな解説役になっていない。ほかの子を全員同じ理解度で書いていない
20. **史実優先テスト**: 人物体験で性格を出すために、実在人物の目的・立場・知識・選択・結果を変えていない。見学中の先走りやいたずらは、別の子が直後に反応し、必要な後始末まで場面内で扱っている
