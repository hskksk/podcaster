# 比喩表: 戦国（540-28 戦国の世）

応仁の乱のあとの、国ごとに大名が自分の力でおさめる時代。`story-rules.md` の全時代共通表（政治→国の大事…など）と、`武士・幕府.md` の基本語（土地→公園、家来→仲間、命令→言いつけなど）も併用する。

## 戦国の基本

| 発話で避ける語 | 発話での言い方 | 補足 |
| --- | --- | --- |
| 戦国大名 | 自分の力で国をおさめる大名 | note に定義。発話では「国のリーダー」と言ってもよい |
| 下剋上 | 下の人が上の人をたおすこと | note に定義。`{% term real="下剋上" %}下の人が上の人をたおす{% /term %}` の形も可 |
| 守護代 | 守護の代わりに国を見る人 | 守護＝見はりの人（`武士・幕府.md`） |
| 分国法 | 国ごとのきまり、大名が作ったきまり | note に「大名が自分の国のためにつくった決まり」 |
| 家臣・家来 | 仲間、家来の仲間 | 友だちの意味の「仲間」には term 不要（`武士・幕府.md` と同じ） |
| 当主・家のリーダー | 家のいちばんえらい人 | 固有の役職名は note |
| 喧嘩両成敗 | けんかした両方が、同じばつを受ける | note に定義 |
| 同盟 | 仲よしの約束、いっしょに戦う約束 | |
| 合戦 | 戦い | |
| 領地（国の一部） | 公園、くらす場所 | `武士・幕府.md` の「土地」→「公園」に従う |
| 城 | 大きな館、とりで | 「城」は子どもにも通じるので、そのまま使ってよい場面もある |
| 鉄砲 | 火をふく、音の大きい道具 | 南蛮人（ポルトガル人）は「外国の人」と言い換える |
| 織田・今川などの大名名 | 人の名前として発話してよい | 固有名詞は対象外 |

## 注記で扱う語

- 戦国大名・下剋上・分国法・喧嘩両成敗は、初出の `note` で定義する。発話内では言い換えか、`term` の `real` で示す
- 同じ語の定義を、同じ日に `note` で繰り返さない（note 重複テスト）

## くまぴー・みじゅぴー向けのボケ

- 「下剋上」を聞いて「げこくじょう？」「くだものを切るの？」などの勘違いは可。ただし、直後に別の子が具体的に反応し、正しい言い方はやさしく直す
- 「鉄砲」を聞いて「花火？」と勘違いするのは可。撃つと危ないことは、別の子が必ず言う
