# 比喩表: 江戸（540-29 江戸幕府の成立）

徳川家康が江戸に幕府をひらいてから、大名をしばって国をおさめた時代の制度語。`story-rules.md` の全時代共通表（政治→国の大事…など）と、`武士・幕府.md` の基本語（土地→公園、家来→仲間、命令→言いつけ、征夷大将軍→武士のリーダーの名前など）も併用する。

## 江戸幕府の基本

| 発話で避ける語 | 発話での言い方 | 補足 |
| --- | --- | --- |
| 江戸幕府 | 江戸のリーダーたち、江戸の将軍のチーム | 幕府（説明時）は「江戸のリーダーたち」 |
| 天下（天下を取る） | 国ぜんたいのリーダーの座 | note に「天下＝国全体の政治を任される地位」。`{% term real="天下" %}国ぜんたい{% /term %}` |
| 大名 | 国を広くもつえらい人 | note に定義。室町の表と同じ言い方 |
| 親藩 | 家康の子どもや兄弟の家の大名 | note で正式名 |
| 譜代大名 | 関ヶ原より前から家康の仲間の大名 | note で「譜代＝昔からの家来の大名」 |
| 外様大名 | 関ヶ原のあとで仲間になった大名 | note で「外様＝よそから後で味方になった大名」 |
| 幕藩体制 | 江戸のリーダーと大名が、国をいっしょにおさめるしくみ | note に定義。発話では「しくみ」「きまり」 |
| 藩 | 大名の国 | 「国」と言い換える。`武士・幕府.md` の「土地→公園」は領地の話に使う |
| 石高 | お米のとれる量でかぞえた国の大きさ | note に「お米の量でかぞえる国の大きさ」 |
| 参勤交代 | 大名が、江戸と自分の国を行ったり来たりするきまり | note に定義 |
| 武家諸法度 | 武士と大名のための決まり | 分国法の江戸版として「大きなきまり」と言ってもよい。note に正式名 |
| 一国一城令 | 大名のお城は、国に一つだけにするきまり | note に定義 |
| 旗本 | 将軍の直接の家来 | 「直接」は `term`、発話では「将軍のすぐそばの家来」 |
| 御家人 | 将軍の家来（旗本以外） | 室町表の「御家人」と同じ。発話では「ご家来」を使わず `武士・幕府.md` の方針に従う |
| 老中 | 江戸のリーダーの中で、大事なことを相談する人 | note に「老中＝将軍の下で政治をまとめる役」 |
| 鎖国 | 外国との行き来を、一部の場所だけにしぼること | note に定義。発話では「外国の船をしぼった」 |
| 出島 | 長崎の海に作った小さな島 | 固有名詞は発話してよい。説明は note |
| キリスト教（天主の教え） | 神さまの教え、外国から来た教え | 禁止のきまりは「信じることを禁じた」と言い換える |
| 島原・天草の一揆 | キリスト教を信じる人たちの大きな反乱 | note に「1637年、島原・天草の農民らの反乱」。反乱は「おこった」 |
| 関ヶ原の戦い | 家康と三成の大きな戦い | 地名・人名は発話してよい |
| 征夷大将軍 | 武士のリーダーの名前 | 「将軍」だけで足りる場面が多い |

## ぬいぐるみの勘違い例

- 天下：「国ぜんたいのリーダーの座」。「てんかって、お空のこと？」などの勘違いは可。直後に別の子が具体的に反応してやさしく直す
- 参勤交代：「さんきんこうたい？ こうたいでごはんを食べるの？」などの勘違いは可。直後に別の子が江戸と国の往復だと説明する
- 鎖国：「くさりでしばる？」の勘違いは可。外国の船をしぼる、と別の子が必ず直す
