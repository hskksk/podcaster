# 比喩表: 武士・幕府（540-25 / 540-26、室町後期の節は 540-27）

鎌倉〜室町の武士社会の制度語。`story-rules.md` の全時代共通表（政治→国の大事…など）も併用する。

## 鎌倉・室町の基本

| 発話で避ける語 | 発話での言い方 | 補足 |
| --- | --- | --- |
| 土地（所領・恩給・守る対象） | **公園**（もらった公園、公園をまもる、新しい公園） | note に「土地」。`{% term real="土地" %}公園{% /term %}` |
| 土地の境目 | 公園のフェンス、公園と公園の境 | scene も同様に `term` 可 |
| 本拠地 | みんなが集まる場所、**ホーム** | 食べ物ジョークは可 |
| 家来（一般） | 仲間、一緒に戦う人、頼朝さまの側のみんな | note に「家来」「御家人」。**友だち意味の「仲間」には `term` 不要** |
| 主君 | 頼朝さま、リーダーなど **具体の人** | note に「主君」 |
| 御恩・奉公 | ごほうび、お仕事 | 初出は note。発話で「御恩」「奉公」と言う必要はない |
| 地頭 | 見はりの人 | 守護（役）と混同しない |
| 守護 | 見はりの役、見はりの人 | 文脈で役／人を分ける |
| 年貢 | お米やお金を集める | |
| 幕府（説明時） | **鎌倉のリーダーたち**、鎌倉チーム | 室町・京都の場面では **将軍のチーム** |
| 朝廷 | 京都のえらい人たち、天皇の正式な側 | |
| 命令（堅い） | 言いつけ、頼まれごと | `real="命令"` または `real="幕府の命令"` |
| 征夷大将軍 | 武士のリーダーの名前 | note に正式名称 |

**くまぴー向けボケ**: 公園なら「すべり台」「ブランコ」「おやつがとれる公園（→ツッコミで訂正）」など。

## 室町後期（540-27 応仁の乱など）

| 発話で避ける語 | 発話での言い方 | 補足 |
| --- | --- | --- |
| 守護大名 | 大きな見はりの人 | 守護との関係は note |
| 大名 | 国を広くもつえらい人 | 文脈で「大名っていうの？」と子ども語可。必要なら `term` |
| 管領 | 将軍を助けて国のことをまとめる人 | note に「管領」 |
| 御家人 | 正しい名前は note で。発話で「ご家来」と言わない | 「正しい名前は、御家人…」など |

応仁の乱週は **公園・幕府比喩が主題でない日** もある。発話に上表の語が出るときだけ言い換え＋`term` を適用する（出ない語を無理に比喩しない）。
