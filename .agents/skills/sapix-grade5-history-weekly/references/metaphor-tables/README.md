# 時代別比喩表

ぬいぐるみの発話で使う **言い換え＋`term`** は、全時代を1枚にまとめない。単元ごとに **比喩表ファイル** を用意し、記事執筆は必ずその表に従う。

## いつ・何を読むか

| 層 | 場所 | 内容 |
| --- | --- | --- |
| 全時代共通 | `story-rules.md` の「発話で避ける語」 | 政治・随筆・国風文化など、教材横断の言い換え |
| 時代・単元別 | このディレクトリの `*.md` | その週の物語で出やすい制度語・社会語の比喩と `term` の付け方 |

執筆前に **`curriculum.md` で選んだテキスト** に対応する比喩表（下表）を開く。表に載っていない試験用語が週のテーマで **発話に出る** ときは、**記事を書く前に** 表へ行を足す。

## 記事より先に表を直す（必須手順）

新しい時代・単元に入る、または既存表に **載っていない語** が今週の発話に必要になったとき:

1. **週のテーマ割り当て**（月〜金）を決める（`SKILL.md` ステップ1）
2. 各日の focus / theme と `curriculum.md` を見て、発話に出しうる **硬い語・制度語** をリストアップする
3. 対応する比喩表ファイルが無ければ **新規作成**、あれば **行を追加**（避ける語・言い換え・`term` の例・補足）
4. 表だけを **先にコミット** する（例: `docs(juken): add metaphor table for 戦国`）。記事ファイルはまだ add しない
5. 更新した表を正本として **5日分の `.mdoc` を執筆** する
6. 記事を別コミット（または同 PR 内の2コミット目）で push する

表と記事を同じコミットにまとめてもよいが、**表なしで記事だけ先に書かない**。エージェントは表の追加を忘れたら執筆を止め、表を直してから再開する。

## 比喩表1行の書き方

`武士・幕府.md` をテンプレートとする。

| 発話で避ける語 | 発話での言い方 | 補足 |
| --- | --- | --- |
| 教材用語 | ぬいぐるみが想像できる言い換え | `note` / `term` / 仲間の例外など |

- frontmatter の `unit`・`theme`・note 属性内・固有名詞は比喩表の対象外でよい
- 言い換えた箇所は発話で `{% term real="教材用語" %}言い換え{% /term %}`（`story-rules.md` の `term` 節）
- 友だち意味の「仲間」など、表に **例外** を書く

## 提出前チェックとの対応
