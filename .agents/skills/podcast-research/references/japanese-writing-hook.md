# 日本語の執筆（`japanese-writing`）

レポート本文を日本語で書くときは、リポジトリに **`japanese-writing` スキル**（`.agents/skills/japanese-writing/`）が入っていれば、**執筆前と提出前の推敲でそのスキルを読み込み、手順に従う**。情報設計と章立ては本スキル（podcast-research 系）の指示のまま、語・文・表記の作法は `japanese-writing` に任ねる。

未インストールなら:

```bash
npx skills add hskksk/agent-skills --skill japanese-writing
```

（[skills.sh 上の説明](https://skills.sh/hskksk/agent-skills/japanese-writing)）

スキルが無い環境では調査の正確さを優先し、日本語の追加推敲は省略してよい。
