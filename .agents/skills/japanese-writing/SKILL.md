# 日本語で書く

日本語の文章を書く、英語から訳す、読みにくさを直すときに使う。正本は `references/japanese.md`。**執筆前と推敲前に、章の順（第1章→第4章）で最後まで読む。**

## いつ使うか

- 日本語の技術文、レポート、記事、ドキュメントを書く
- 英語の文章や英語の思考を日本語にする
- 直訳調・AI構文・硬い官公庁調を直す

英語だけの成果物には使わない。

## 手順

1. **`references/japanese.md` を読む**（ミクロ→マクロの順）。
2. **初稿を書く**（第1章の保護リストにある定着語はそのまま使う）。
3. **第1章（語彙）** — 1.2 の比喩置換、1.3 の have、1.4 の名詞化連鎖。1.2「定着した言い回し」は削らない。条文がぶつかったら冒頭の**優先順位**に従う。
4. **第2章（文構造）** — 修飾の距離（2.1）、主述のねじれ（2.2）、は／が（2.3）。2.2 の定着主語＋*tells us* は 1.2 の示す／教えてくれるでよい。リスト外の擬人化だけ直す。
5. **第3章（推敲）** — 3.1 の4段階、3.2 の空 rhetoric・AI構文・比喩の借り語、制作メタの露出禁止。3.3 の表記（読点・中黒・英数字）に合わせる。
6. **第4章（段落・配置）** — 接続詞（4.1）、数値は表（4.2）、太字は4.3（基本1〜2箇所／必要なら2点以内で超過可）。

## ガイドの章立て（参照用）

| 章 | 内容 |
| --- | --- |
| 第1章 | 語彙・比喩・持つ・名詞化 |
| 第2章 | 修飾、主述、は／が |
| 第3章 | 簡潔化、レトリック／AI構文、表記 |
| 第4章 | 段落接続、表、太字 |

## このスキルが扱わないこと

長文の論証設計や、特定プロダクト向けのレポートテンプレート全体は含めない。段落の論理は第4章まで。
