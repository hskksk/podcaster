# Web サーベイの進め方

Web を使ってテーマを体系的に調べるための手順。問いの設定、検索計画、情報収集と評価、調査範囲の確認までを扱う。詳細は `references/` にまとめ、このファイルでは作業順と参照先を示す。

## いつ使うか

- Web 検索とページ取得を使って、特定のテーマや問いを体系的に調べる
- 複数の観点から情報を集め、根拠や情報源を整理する

成果物は、問いと範囲のメモ、観点ごとの調査メモ、出典一覧、未確認事項である。

## 手順

1. **問いと範囲を定める。** `references/scope-and-questions.md` に従い、調べる問い、対象範囲、対象外を作業メモに書く。
2. **検索計画を立てる。** `references/search-plan.md` で問いをサブトピックに分解し、検索語と調べる順序を決める。
3. **情報を集めて記録する。** `references/web-research.md` に従い、検索とページ取得を繰り返す。根拠、出典、信頼性、未確認事項を調査メモに記録し、必要に応じて計画を更新する。
4. **調査範囲と根拠を確認する。** `references/evidence-bar.md` を使い、問いに必要な観点が調べられ、十分な幅と質の情報源が集まったか確認する。不足や偏りがあれば追加調査する。
